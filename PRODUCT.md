# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Burak Soykan's personal portfolio presents software projects, engineering experience, technical writing, selected reading, and application support links. The user has requested a complete visual redesign because the existing presentation feels generic and AI-generated.

## Users

The user confirmed that projects and engineering work should be the primary focus. Audience assumption: technical peers, collaborators, and prospective clients evaluating the work. The content covers multiple software domains rather than a narrow industrial-only identity.

## Capabilities and Constraints

- Existing static HTML, CSS, and JavaScript hosted through the repository's GitHub Pages workflow. Preserve the deployment structure and URLs.
- Preserve Turkish and English home, blog, article, and reading pages; preserve applications, application support/privacy contacts, project repositories, and the playable game.
- The user requested removal of the general contact section ("Birlikte çalışalım" / "Let's talk") and navigation links to that section.
- Preserve factual descriptions. Do not invent clients, employment, usage statistics, testimonials, or product screenshots.
- Application privacy and deletion documents retain their legal content. The game build and its runtime are outside the design implementation.
- Keep existing delivery-map content accessible without making it dominate the home page.

## Evidence on Hand

`portfolio-site/index.html`, `en.html`, `apps.html`, `posts/`, and `data/reading-list.json` contain the portfolio's content and links. No verified project screenshots or portrait assets are supplied.

## Product Principles

- Real projects should be easy to discover and inspect.
- Clear, readable writing precedes decoration.
- Navigation and reading remain usable on small screens and with keyboard input.
- UI work remains local until publication is explicitly requested.
